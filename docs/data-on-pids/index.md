# Data on PIDs

*Basic data on existing PID systems*

This chapter provides a short, structured outline of each PID system discussed in the landscape analysis and the recommendations. Each page follows the same layout, so that PID systems can be easily compared:

- **Where to get started as a Swedish organisation?** - how to get access to the PID system, for example through a Swedish [PID actor](../pid-actors-sweden/index.md) or an international provider.
- **PID parameters** - scope, syntax, resolvers, kernel metadata, standards and documentation.
- **PID ecosystem** - the organisations that fill each role in the [PID ecosystem](../pid-concepts/pid-ecosystem.md), such as the PID authority and PID providers.
